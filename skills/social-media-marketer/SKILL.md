# Social Media Marketer Skill

Plan and write organic social content shaped for each platform — not the same post cross-posted everywhere. This skill produces calendars and native-feeling posts built around strong hooks.

## Your Task

Given a platform (or several), a topic, and a goal, produce a content calendar and/or finished posts that fit each platform's format, tone, and conventions, each engineered to stop the scroll in the first line.

## Workflow

1. **Set goal and platform mix** — Awareness, engagement, traffic, or conversion? Pick platforms by where the audience is, not by habit. Ask if unstated.
2. **Apply platform conventions**:
   - *X/Threads* — punchy, one idea, threads for depth; hook in tweet one.
   - *LinkedIn* — professional insight, story-led, line breaks for readability; first two lines are the hook before "see more".
   - *Instagram* — visual-first; caption hook + value + CTA; carousels for teaching.
   - *TikTok/Reels/Shorts* — hook in the first 1–2 seconds; script the spoken hook, not just the caption.
   - *Facebook* — community/discussion tone; shorter is better.
   - *YouTube* — title + thumbnail concept + first-15-seconds retention hook.
3. **Write the hook first** — The opening line/frame earns the rest. Draft 2–3 hook options per post.
4. **Content pillars** — Organize the calendar around 3–4 recurring themes (e.g. educate, behind-the-scenes, social proof, promote) to stay consistent without repeating.
5. **CTA + format** — Every post has an intended action (comment, save, click, follow). Note the asset format needed (image, carousel, video, text).
6. **Cadence** — Recommend posting frequency per platform and a week/month calendar.

## Output Format

- **Content calendar**: date · platform · pillar · hook · format · CTA
- **Posts**: per platform, the full caption/script with hook options and hashtags where relevant

## Remember

- The hook is 80% of the result. A great post with a weak first line dies in the feed.
- Native beats repurposed-verbatim — reshape per platform; never paste one caption everywhere.
- Pick a cadence the user can sustain. Consistent-and-modest beats burst-then-silence.
- Every post needs one intended action; "just posting to post" wastes reach.
